## 📌 Project Overview

Interactive hotel booking analysis dashboard designed to analyze booking performance, revenue, cancellations, market segments, lead time, and customer booking behavior.

The dashboard transforms hotel booking data into meaningful insights through KPIs, interactive filters, and data visualizations.

---

## 🎯 Project Objectives

The main objectives of this dashboard are to:

- Analyze overall hotel booking performance.
- Monitor total bookings and total revenue.
- Track the cancellation rate.
- Analyze revenue trends across different years.
- Compare revenue across market segments.
- Analyze bookings based on lead time.
- Identify the countries with the highest number of bookings.
- Provide interactive filtering for deeper analysis.

---

## 📌 Key Performance Indicators

The dashboard includes three main KPIs:

- *Total Bookings:* 40,060
- *Total Revenue:* $6,930,635

## 📈 Dashboard Analysis

### 💰 Total Revenue Per Year

This visual analyzes the total hotel revenue across different years and helps identify changes in revenue performance over time.

### 📊 Revenue by Market Segment

This chart compares revenue generated by different market segments:

- Online TA
- Offline TA/TO
- Groups

It helps identify which market segments contribute the most to hotel revenue.

### 🏨 Booking by Lead Time

This visualization categorizes bookings based on lead time:

- Short
- Medium
- Long

It provides insights into how far in advance customers make their hotel reservations.

### 🌍 Top 5 Countries by Bookings

This visual highlights the five countries with the highest number of hotel bookings and provides an overview of the main booking markets.

---

## 🎛️ Interactive Filters

The dashboard includes interactive filters that allow users to analyze the data based on:

- *Customer Type*
- *Year*
- *Hotel*

These filters make it easier to explore specific customer segments, years, and hotel types.
